# HUD artwork

`punch.png` and `sound.png` are original AI-generated UI pictograms created with the built-in image generator on 2026-10-19 for this project. They are separate from the SpriteCollab Pokemon artwork and must not be credited to its artists. A transparent two-cell source sheet was extracted, alpha-trimmed and nearest-neighbor resized to 40x40 for the existing pixel-art scene.

HUD frames, progress borders and typography are native HTML/CSS; no generated screenshot is used as a game surface. The Pokemon portrait retains its pinned source and named artist in the Pokemon credits.
